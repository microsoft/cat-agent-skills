# Output outline: Agent adoption at scale: <scope>

Use this outline for the Word report (default). The deck and HTML page follow the same order. Every output starts with the executive summary.

Style: American English, short sentences, no em dashes, no filler words. Cite Learn after each framework statement as "(Learn: <page title>)" and list URLs in Sources. Label illustrative examples as such.

## Word report

1. **Executive summary** (half a page)
   - Scope and sponsor
   - Three findings, one sentence each
   - The scale-breaker per selected pattern and the weakest pillar
   - The top three leader decisions
   - The largest unknowns
2. **How to read this report**
   - The three Learn frameworks and the loop (patterns, maturity, CoE)
   - The frameworks are planning guidance, not certification or benchmarks
3. **Pattern map**
   - Table: initiative, pattern, serves, assist or execute, risk tier, rationale, straddle flag
4. **Maturity diagnostic**
   - Table: pillar, level, confidence, evidence (source and date), unknowns
   - Radar chart (current vs target), exact values labeled
   - Note: no overall score, by design
5. **Gap analysis**
   - Gap table per pattern and combined (from gap_calc.py)
   - Learn-named and computed scale-breaker, weakest pillar, dependencies
   - Readiness verdict per pattern
6. **Roadmap**
   - 90 days, 6 months, 12 months; one or two priority pillars; one level at a time
   - Each action tied to a pillar and a Learn page
7. **CoE blueprint**
   - Structure per pattern and the blend
   - Four functions with first moves
   - Risk tiers and controls per initiative
   - Intake and front door
   - Operating rhythm
   - Value metrics with baselines and targets; cost ownership
   - Failure-mode check (gatekeeper, ghost, perfectionist)
8. **Leader decisions**
   - Table: decision, options, recommendation, informed by (Learn page)
   - Note that the list is the advisor's synthesis
9. **Illustrative use cases for <function or industry>**
   - Two or three per relevant pattern, labeled illustrative
10. **Assumptions and unknowns**
11. **Sources**
   - Learn URLs used, with access date
   - User documents used, by file name
