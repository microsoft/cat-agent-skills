# Reference structure only

Runtime Markdown is generated by scripts/render_ncr.py after source replay; do not hand-fill this legacy template. Required sections: DRAFT/QE review, open escalations, lot ID, all characteristics with null-aware fields, grades, watch list, proposed review only, CAPA handoff, exact contract appendix. No universal containment policy is encoded.

Release 3.1.1 supports Markdown (.md) only. This reference is not a DOCX/PDF converter
or an alternate rendering path. Explain unsupported format requests and ask whether
Markdown is acceptable; never write Markdown into a file labelled as another format.
