# Proactive Clarification Discipline

A general agent-quality skill for the question every agent gets wrong in one
direction or the other: when to ask before starting work, and when to just
proceed. This skill gives a concrete test instead of a vague instinct: would
the different reasonable readings of the request actually lead to different
work? If yes, ask one focused question. If no, proceed and state the
assumption.

## Why both failure modes matter

An agent that asks constantly is exhausting to work with. An agent that
silently guesses wrong on something consequential wastes more time than it
saved. This skill is built around avoiding both: a short decision test for
whether to ask, a preference for concrete options over open-ended questions
when asking, and a habit of stating assumptions explicitly when proceeding
without asking, so a wrong guess is cheap to correct.

## Where it applies

Any conversational or task-taking agent. It's especially useful paired with a
skill that maintains cross-session memory, since a stored preference like
"just proceed, don't ask" or "always confirm scope first" lets this skill
stop re-deciding the same question every session.
