# Business Case Composer

A Microsoft-built Agent Skill for Cowork that turns a customer-specific
problem and proposed investment into an evidence-backed business-case draft.

## When to use it

Use it to explain the problem, cost of inaction, proposed solution, investment,
and supported value of a customer initiative. It is not a generic product
pitch or a pricing and discount tool.

## Before you start

Provide the customer use case, investment decision, and discovery notes or
other evidence of the customer's need. Include the intended audience and any
approved cost, benefit, or assumption inputs. Authorized connected sources can
enrich the case; live CRM is not required to create a bounded draft.

## Try it

> Build a business case for this customer initiative using the attached
> discovery notes. Separate supported value from missing financial inputs.

## What you get

A concise summary and an editable business-case draft. When grounded inputs
support quantification, the skill also calls for an inspectable Excel model.
Without those inputs, it can produce a qualitative case and a missing-input
table instead of inventing numbers.

## Review and control

This is an individual skill, not a plugin ZIP. Review evidence, units,
currencies, time horizons, and assumptions before using the case. External
actions require separate authorization; creating a draft does not send it.
