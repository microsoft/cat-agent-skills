# Facilitator guide and participant materials

Read this in steps 5 and 6.

## Facilitator guide: section order

1. **Executive summary** (two to four sentences).
2. **At a glance:** audience, level, group size, format, length, start time, constraints.
3. **Learning objectives** with their IDs.
4. **Before the session:** setup per module, materials list, room or virtual setup, a tech check
   15 minutes before start, who co-facilitates.
5. **Run of show:** a table of time, module, minutes and objectives.
6. **Per module:** heading with minutes and clock time, then
   - Talk track: what to say, in plain sentences the facilitator can read aloud. Include one question to
     ask the room.
   - Key points with source refs.
   - Setup for this module.
   - If something fails: the module fallback.
   - Each activity: objective, timebox, numbered instructions, materials, expected output, debrief
     questions, fallback, sources.
   - "Timing: N minutes."
7. **Gaps in the sources:** what the sources did not cover and how the session handles it.
8. **Sources:** every source with its ID, title and location.

## Talk track rules

- Write it to be spoken: short sentences, no bullet fragments.
- Open each module with why it matters to this audience, in one or two sentences.
- Close each module with the checkpoint: two or three things everyone should have done.
- Prompt the facilitator to watch the clock at the halfway point of each exercise.
- Include a "time saver" line for modules over 20 minutes: what to cut if the session runs late.

## Timing discipline

- Show the timebox on every activity slide.
- Start the timer when instructions end, not when they start.
- Give a two-minute warning in every exercise over 10 minutes.
- If the session runs more than five minutes late, cut from best practices before cutting from hands-on
  time.

## Participant workbook

1. **Executive summary.**
2. What you will be able to do (the objectives).
3. Agenda.
4. One **exercise sheet** per hands-on activity: title, timebox, goal, numbered steps, what you need,
   what you produce, a work area (table or lines), reflection questions.
5. Sources.

The workbook holds no facilitator-only content: no fallbacks, no talk track, no answer keys. Answer keys
go in the facilitator guide.

## Pre-read and pre-work (optional)

- Executive summary, time needed (in allowed minutes), what to read with source refs, what to bring.
- Keep it under 15 minutes of effort.

## Feedback survey (optional)

- Three to six questions: one confidence scale per objective or one overall, one "most useful", one
  "what to change". Anonymous by default.

## Follow-up email draft (optional)

- Starts with "DRAFT. Not sent. Review, then send it yourself."
- Subject, a short summary, three to five points, what is attached, sign-off.
- Never send it. Never create it in the mailbox unless the user asks for a draft there and a mail tool is
  available; even then it stays a draft.
