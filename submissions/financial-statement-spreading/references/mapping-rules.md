# Mapping rules: candidate rows → normalized v2 JSON

Read this file before completing the draft that `draft-map` writes (or before writing the normalized JSON by hand). Structure and field descriptions are in `statement-schema.json`; canonical line ids and formulas are in `metric-definitions.md`.

## Mapping checklist
Work through the list for every report. Record each judgement call; it goes into the delivery reply.

| Check | What to confirm |
|---|---|
| Statement | Consolidated primary statement, not a summary, ten-year table, note or parent-company statement |
| Columns | Which period each column covers (annual, 9M, H1, 18 months) and the balance-sheet date |
| Unit | Exactly as printed (`ones`, `thousands`, `ten_thousands`, `lakhs`, `millions`, `crores`, `billions`) |
| Sign | Expenses and outflows negative; revenue, assets, liabilities and equity positive |
| Totals | Every printed subtotal declared with `total_of` and its printed value |
| Zero vs empty | Enter 0 only when the document shows nil for that period: a "–" or blank in a column whose subtotal is printed, or a note stating there is none. A figure the document does not give for that period stays empty (null), never 0 |
| Cost of sales | `cogs` only from a printed cost of sales / cost of goods sold line; never relabel a nature-of-expense line |
| Debt | Every interest-bearing borrowing tagged `debt` (incl. lease liabilities from the notes); notes payable / acceptances tagged `debt_like`; no borrowings → a 0 line tagged `debt`; every debt line needs a value in every period the document covers (comparative note column); apply the zero-vs-empty rule above, so a note that gives only the current year leaves the prior year empty and net debt / ROIC N/A for it. That is correct, not an error |
| Capex | Investing outflows for PP&E **and** intangible assets / software / capitalised development, and capitalised interest paid in investing, all count: `capex` for the PP&E line, the tag `capex` on the others (draft-map tags the usual labels; confirm) |
| One-offs | Impairments tagged `impairment`; other one-off gains/losses tagged `non_recurring`; reported EBITDA supplied when the report gives one |
| Attribution | Every non-owner share of profit (NCI, perpetual holders) tagged `attribution` |
| Provenance | Every non-null value has a document and page/sheet |
| Status | Audited or unaudited; restated comparatives flagged |

## Detailed rules
- One ordered line list per statement (`income_statement`, `balance_sheet`, optional `cash_flow`, optional `supplementary`), in the statement's order, grouped with `section`. Keep the source wording in `label` and `sources[year].label`. If the entity presents no cash flow statement (e.g. FRS 101 / IAS 7 exemption), omit it; cash flow metrics then show N/A.
- **Entity type.** Set `entity_type`: `operating` (default), `conglomerate` (group whose main business is non-financial but which owns a bank, card, securities or insurance arm: operating metrics plus financial-services metrics; tag only non-financial-services borrowings as `debt`, never bank deposits; supply `cash_non_financial` = cash excluding the banking/securities/insurance businesses if disclosed (segment or "non-financial" disclosures), otherwise net debt is N/A; `loans` = the bank's customer loans only (loans funded by the deposits; card loans funded by the card company's own borrowings go in a separate memo line), `deposits` = the bank's customer deposits; tag the financial businesses' balance-sheet flows inside operating cash flow `fs_operating` so free cash flow can be shown excluding them: exactly the changes in customer deposits, in loans of the card and banking businesses, in call loans, in receivables/payables under securities borrowing or lending, in financial assets and liabilities of the securities business, in derivative assets and liabilities, and in insurance-business assets and liabilities; never working capital, tax paid or the other businesses' lines; the workbook lists the tagged lines), `bank`, `insurer`, `broker_dealer`, `asset_manager`, `payment_institution` or `other_financial`. For `bank`/`insurer`/`broker_dealer`/`other_financial` the skill drops liquidity, working-capital, EBITDA and net-debt measures and computes sector metrics instead. Map `revenue` to **total operating income** (banks) or total revenue/insurance revenue, and supply where available: `net_interest_income`, `operating_expenses` (negative), `impairment_losses` (negative), `loans`, `deposits`, `interest_earning_assets`, `insurance_revenue`, `insurance_service_expenses` (negative), and in `supplementary` the reported `cet1_ratio`, `total_capital_ratio` or `solvency_ratio` as decimals.
- **Citations for OCR text.** The `document` in every source is the user's PDF name, never the `.txt` made from it; page numbers are the PDF's. (`ocr-pdf` records the PDF name in the text file and `analyze` applies it.)
- **Note figures in another unit.** When a note gives a figure in a different unit from the statements (e.g. k EUR against EUR), enter the converted value and write the conversion in the location, e.g. `p.30 (note in thousands: 1 093 × 1,000)`; the source check then looks for the printed figure.
- **OCR'd (scanned) statements.** OCR text often drops empty cells, so a lone number may belong to either year column. Resolve each ambiguous value with the printed subtotals (the value must make that column's total tie), and list any still-ambiguous values in the mapping summary for the user to confirm. Never guess a column; the tie-out checks will flag a wrong allocation.
- **Company-reported ROE.** When `shareholders_equity` includes perpetual / other equity instruments, the workbook shows both ordinary-shareholder ROE and ROE on owners' equity (the basis most companies report).
- **Distributions from associates/JVs.** If material dividends or distributions from equity-accounted investees are classified in investing cash flow (e.g. dividends from a large joint venture shown under investing activities), map them to `distributions_from_associates`; an adjusted cash conversion is then shown alongside the statutory one.
- **Statements without titles.** Statutory layouts (e.g. French comptes sociaux: bilan actif/passif, compte de résultat) may have no title on the page; `locate-statements` recognises them by structure. Small-company statutory accounts often have no cash flow statement: omit `cash_flow`.
- **Period length.** A period that is not ~12 months (e.g. an 18-month comparative after a year-end change) keeps `period_type` "annual" with its real `days`; returns are annualised and growth against a 12-month period is N/A.
- **Cost of sales.** Map `cogs` only when the income statement presents a cost of sales / cost of goods sold line (expenses by function), or when a note splits a single face-of-statement expense total and prints a "cost of sales" line within it (e.g. an "Expenses" note that lists cost of sales, employee costs and D&A): map the note's lines as the components of that total, citing the note page. If expenses are presented by nature (purchases, staff costs, fuel, depreciation as separate lines, typical of utilities), leave `cogs` and `gross_profit` out: gross margin and inventory/payables days are then N/A. Never relabel a single nature-of-expense line as cost of sales.
- **Blanks and dashes.** A line the statement prints as blank or "–" in a column whose subtotal is printed is nil: enter 0 with its source, so the subtotal can still be tied out. A value the document does not disclose at all stays null (N/A), never 0.
- **Sign convention:** expenses and cash outflows negative; revenue, assets, liabilities and equity **positive**. Many reports print liabilities in brackets (e.g. a "net current liabilities" layout): enter them as positive numbers. The sign checks fail if liabilities are negative. Genuine deficits keep their sign: accumulated losses, negative reserves and negative total equity are entered negative (draft-map keeps them and only normalises bracketed liabilities).
- Declare every subtotal with `total_of`, and record its reported value when the statement prints one so the tie-out check can compare. When the statement does not print a total the skill needs (e.g. total assets, total liabilities in a net-assets layout), add it as a `total_of` line without a value.
- Tag every interest-bearing borrowing line (current and non-current) with `"tags": ["debt"]`.
- When the statement shows profit attributable to shareholders and shareholders' funds, add `net_income_attributable` and `shareholders_equity`; ROE and EPS then use the shareholder basis.
- Every non-null value needs `sources[year]` (or `source`) with document and page.
- **Periods.** Declare each column in `periods` with `label`, `days`, `flow_end`, `balance_date` and `audited`. For interim reports set `"period_type": "interim"`: e.g. a Q3 report has income/cash flow columns Jan–Sep this year and Jan–Sep last year (`days` 273/274, `label` "9M 2025"/"9M 2024"), while its comparative balance sheet is the prior **year end** (`balance_date` "2024-12-31"). The skill then labels columns correctly, annualises returns and turnover (×365/days), compares growth only like-for-like, and skips cash checks across mismatched dates. Never label interim columns as fiscal years.
- **Unaudited.** If the report states the statements are unaudited (e.g. 审计类型：未经审计), set `"audited": false`.
- **EBIT.** If the reported operating profit is **after** finance costs (China Accounting Standards 营业利润, and some other local GAAPs), set `"accounting_framework": "CAS"` (or `"ebit_method": "pretax_plus_interest"`). Map 利息费用 (interest expense, usually a "其中" line under 财务费用) to `interest_expense` as a negative number; EBIT is then profit before tax + interest expense. Never map 营业利润 to EBIT directly. **No operating profit line** (Ind AS / Schedule III layouts list expenses including finance costs, then profit before tax): EBIT = revenue less the operating expenses, excluding other income and finance costs; `draft-map` adds this as a derived `operating_income`. Never use profit before tax + finance costs there: it keeps other income (treasury income) inside EBIT.
- **Perpetual bonds / other equity instruments** (e.g. 其他权益工具—永续债) inside equity attributable to the parent: give that line the id `perpetual_bonds`; ordinary-shareholder ROE and book value exclude it. Add the distributions to perpetual holders as `perpetual_distributions` (positive; e.g. 归属于永续债持有人的利息) so they are removed from attributable profit, **only when the owners' profit line still includes them** (Chinese and Japanese reports; when the income statement shows the perpetual holders' share as its own attribution line, do not add it). Prefer the amount accrued in the statement of changes in equity over the cash paid; if the report does not give them, ROE is shown on net income / total equity instead of the ordinary basis. When the owners' profit line already excludes the perpetual holders' share, set the top-level field `owners_profit_excludes_perpetual: true` (with `edit-map --field`) so the ordinary basis is used without a distributions line.
- **Restricted cash.** Map the balance-sheet cash total to `cash`. If the restricted part (restricted cash, pledged or long-term deposits) is shown or disclosed, add it as `restricted_cash`; the skill then uses cash excluding restricted deposits for net debt, invested capital and the cash check. Link it to `cash` according to the breakdown. **Complete breakdown** (the note splits the whole cash total, e.g. cash at bank + restricted cash): add every part as a line and list all of them in the `total_of` of `cash`; `total_of` *calculates* the total, so it must be complete (with cash of 100 and only `restricted_cash` 20 as its `total_of`, cash would become 20). **Only the restricted part disclosed** (the printed cash total includes it, the rest is not split): do not use `total_of`; tag the line `included_in_cash` (`edit-map --tag restricted_cash=included_in_cash`), so cash keeps its printed total and the restricted part is deducted from it. **Separate line outside the cash total:** leave it as its own line, untagged. **Not disclosed:** the cash check shows REVIEW (explainable) rather than FAIL.
- **Debt** = borrowings (loans, bonds, notes, overdrafts, commercial paper) and lease liabilities, from the borrowings / financial liabilities note or the company's net debt reconciliation. Never tag a caption such as "financial liabilities" or "other financial liabilities" as debt as printed: it also holds derivatives, deferred consideration and other items. Split it with the note and tag only the borrowings and leases; `analyze` prints a HINT when a debt-tagged line has such a caption.
- **Debt-like items.** Tag notes payable / bank acceptance bills (应付票据) and similar financing-like liabilities with `"debt_like"`; they are reported as a net-debt sensitivity, not in reported debt.
- A single annual report usually gives two years. Average-based ratios need an opening balance, so ask the user for the prior year's report if they want ratios for both years.

## Further rules
- **Leases.** Lease liabilities are often inside "other liabilities", "trade and other payables" or "other financial liabilities". Take them from the lease / borrowings note and add a `lease_liabilities` line (supplementary if not on the face) tagged `debt` (or `debt_like` if you want them only as a sensitivity). When a note splits a printed line into borrowings and leases, map them as two lines.
- **Interest expense** = interest on borrowings and leases (finance costs note). When the face line is a total ("finance costs", "financial expenses") and the note splits it, map the note's interest on borrowings and on leases as `interest_expense` and keep the rest (provision unwind, FX, derivative movements) as separate lines; `analyze` prints a HINT when only the total is mapped. Capitalised interest may be supplied as `capitalised_interest` (memo).
- **EBITDA.** The workbook's headline EBITDA is always **before impairments**: if the company's reported figure is stated after an impairment, the impairment is added back and the as-reported figure is kept as a memo line (with its own net debt / EBITDA memo). If the report gives EBITDA / EBITDAF (often in the segment note; `draft_review` lists the pages), map the **statutory** figure as `ebitda` (supplementary, source the page): the one the company reconciles to its statutory income statement (e.g. "Statutory EBITDA", or "EBITDAF" of the consolidated group), not a figure that adds the share of joint ventures and associates on top of the group's own. Never use an "underlying" or "adjusted" measure as `ebitda` (add it as an `underlying_` memo line instead). Name the measure in the label and use the same definition for every period. When the years are printed on different pages, give per-year `sources` (`"sources": {"2023": {"document": "…", "location": "p.209"}, "2024": {…, "location": "p.208"}}`) instead of one `source`. If the reported EBITDA is stated after an impairment, keep it as reported and tag the impairment line `impairment`: the workbook then shows EBITDA and net debt / EBITDA before it. Otherwise the workbook derives EBIT + D&A (+ impairments added back) and labels it "derived". When EBIT includes post-tax results of associates/JVs (`share_of_associates`), also supply `share_of_associates_itda` (their interest, tax and D&A) if disclosed; otherwise the summary warns that derived EBITDA understates.
- **Associates.** Map the share of results of associates/JVs to `share_of_associates` (positive = profit), wherever it sits (inside or below operating profit). NOPAT and the tax rate then exclude it correctly, whether EBIT comes from operating profit, from profit before tax, or from a reported `ebit` line (the engine checks whether a reported EBIT already contains the share by reconciling it to profit before tax; set `"ebit_includes_associates": true/false` only if that reconciliation is not possible).
- **One-offs, scope.** Tag as one-off only: impairments and their reversals (`impairment`), and gains or losses on disposals of businesses, subsidiaries or major assets, restructuring, remeasurements on a change of control or accounting method, and litigation settlements (`non_recurring`). Do **not** tag fair-value movements on derivatives or hedges, foreign-exchange gains and losses, or bad-debt charges, even when the company excludes them from its own underlying profit: they recur every year. The company's own underlying figure goes in an `underlying_` memo line instead.
- **One-offs, symmetry.** Treat gains and losses of the same kind alike: when you tag a disposal, remeasurement or fair-value gain `non_recurring`, tag the matching loss line too (and the reverse), in every period.
- **One-offs.** Tag only income statement lines (the cash flow 'impairment loss' add-back has the opposite sign and is refused). Tag impairments (incl. goodwill write-downs shown as "other charge" — check the note) `impairment`, and gains/losses on business transfers or disposals, restructuring and similar `non_recurring`. The workbook shows net income and net margin before one-offs, adds impairments back to derived EBITDA and removes `non_recurring` gains/losses that sit inside EBIT (e.g. a remeasurement gain in other income: split it out of the face line with the note and tag it), and the findings caveat margins and growth. When the report itemises its own non-underlying, exceptional or adjusting items in a note (`draft_review` lists the pages), go through that list: each item within the one-off scope above is split out of the face line it sits in and tagged; items outside the scope stay untagged. When the face line cannot be split (the item is only in the note), add it as an income statement line with `"section": "memo"` (no `total_of`, not in any subtotal; negative for a charge), with the note page as source, and tag it: a tagged memo line is treated as inside operating profit, so EBITDA and net income before one-offs exclude it while the statement totals are unchanged.
- **Underlying measures.** Company-defined underlying profit or EBITDA may be added as supplementary memo lines with ids starting `underlying_` and labels saying "non-statutory"; they are shown, not used in ratios. Always add the company's profit excluding non-recurring items when the report prints it (e.g. Chinese 归属于上市公司股东的扣除非经常性损益的净利润 → `underlying_profit_excl_nonrecurring`, every period given): when it has the opposite sign to reported profit, the findings say so.
- **Perpetual securities as debt.** When perpetual securities move from equity to borrowings (e.g. after a redemption notice) or a borrowings note shows a perpetual tranche, map that tranche as its own line tagged `debt` and `perpetual`; the workbook shows debt excluding perpetuals and a comparability warning.
- **Opening balances.** When only one or two years are given, take opening equity (and opening shareholders' equity / total assets if shown) from the statement of changes in equity and add supplementary lines `opening_equity`, `opening_shareholders_equity`, `opening_total_assets` with the value in the **first** period's column and the SoCE page as source. When `perpetual_bonds` is mapped, also add `opening_perpetual_bonds` from the same SoCE row; without it the first year's ordinary-shareholder ROE is N/A and the whole ROE row falls back to the total-equity basis (one basis per row, never mixed). First-year average-based ratios are then computed.
- **D&A excludes impairment.** When the cash flow add-back is "depreciation, amortisation and impairment", map `d_and_a` as depreciation and amortisation only (the note splits it) and tag the impairment on the income statement; otherwise the impairment is added back twice.
- **D&A without a cash flow statement.** Take depreciation and amortisation from the operating-profit note as supplementary `d_and_a` (positive). A period whose note prints "-" or nothing for D&A (e.g. a dormant year) gets 0 with its source, not null, or EBITDA is N/A for that period. When the company's EBITDA includes its share of associates'/JVs' EBITDA (segment notes often show "share of ITDA of equity accounted investees"), always add that figure as `share_of_associates_itda`. PP&E-only depreciation and capex may be supplied as `depreciation_ppe` and `capex_ppe` for the fixed-asset roll-forward.
- **Dividends.** Without a cash flow statement map dividends from the statement of changes in equity as `dividends_declared` (negative). When the report states that no dividend was paid, enter `dividends_paid` 0 with that page as source.
- **Trade working capital.** Map `receivables` / `payables` to the trade element when the face line mixes trade, intragroup, prepayments or client money (use the note); keep the rest as separate lines.
- **Lending entities.** Set `"ebit_method": "operating_plus_interest_income"` only when lending or treasury *is the business model* (a finance subsidiary, a treasury company, a consumer lender) and interest is its recurring operating income. Never for: interest on vendor notes or deferred consideration received for a disposed business, interest on intragroup loans or cash balances of a company that has stopped trading, or a payment institution's interest on safeguarded funds. Those stay below EBIT; `analyze` prints a HINT when the setting turns an operating loss into a profit.
- **Payment institutions.** Add both `client_funds` (safeguarded / restricted client cash, asset) and `client_liabilities` (client money owed, liability), always as a pair; the workbook shows the current ratio excluding them. With only one of the two the ratio is N/A and `analyze` says which is missing.
- **Profit attribution.** Tag non-owner shares of profit (non-controlling interests, perpetual securities holders) `attribution`; the check "owners + others = net income" then runs. Do not tag other comprehensive income lines.
- **Cash flow cross-checks.** In an indirect cash flow statement map the starting profit to `cf_net_income` or `cf_pretax_income` so it is tied to the income statement.
- **Restricted cash, implied.** When the report does not disclose restricted cash, the workbook uses the cash flow statement's cash equivalents at the same date (and the next period's opening cash for a prior year end) for net debt, and shows the implied restricted amount. Do not invent a restricted_cash line.
- **Going concern and key disclosures.** Set `"going_concern_uncertainty": true` when the auditor reports a material uncertainty. Add up to five `key_disclosures` (`{"text": ..., "source": {"document": ..., "location": ...}}`): restatements, regulatory breaches, cessation of trading, major disposals, date inconsistencies in the report. Without a cash flow statement, state why in `no_cash_flow_reason` (e.g. "exempt under FRS 101 (IAS 7)").
- **French statutory accounts (PCG).** COGS = achats de marchandises + variation de stock (+ achats de matières + variation) → `cogs` only for a goods-trading business, labelled accordingly; when the company also sells services, add the same amount as supplementary `goods_consumed` (negative, location listing the printed figures, e.g. "p.N (derived: 12,345 + 678)") instead, so days inventory outstanding is computed while gross margin stays N/A; map "créances clients et comptes rattachés" to `receivables` (draft-map does this) so DSO is shown; "emprunts et dettes financières divers" hidden inside "autres dettes" (check the état des échéances note) → split out and tag `debt`; "groupe et associés" loans → separate line (`intragroup_loans`), not cash; écarts de conversion actif/passif → separate lines tagged `fx_translation`. `draft-map` already sets participation des salariés and impôts sur les bénéfices negative, derives `pretax_income` (résultat courant + exceptionnel + participation), takes D&A from "dotations … sur immobilisations" drops the "TOTAL DES PRODUITS (I+III+V+VII)" cross-sums and tags the four "produits / charges exceptionnels sur opérations de gestion / en capital" lines `non_recurring` (exceptional items are outside ordinary activities by definition; tag all four, not only the capital ones); confirm, don't redo.
- **Cash bridging lines.** Lines between opening and closing cash other than the three activities and FX (e.g. "cash held for sale at the beginning of the year", overdraft movements) stay as printed; held-for-sale lines are counted in the cash check automatically, tag any other bridging line `cash_reconciling`.
- **Chinese reports.** Map the "其中" lines for 对联营企业和合营企业的投资收益 (`share_of_associates`) and 子公司支付给少数股东的股利、利润 (memo) when printed. `draft-map` already makes 营业总成本 and its costs negative, 减：库存股 negative, 短期借款 `short_term_debt`, 永续债 under 其他权益工具 a memo line, maps 营业成本 to `cogs`, and drops the "（损失以"-"号填列）" sign note from labels; confirm, don't redo.
