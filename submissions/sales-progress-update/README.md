# Sales Progress Update

A Microsoft-built Agent Skill for Cowork that creates or refreshes a seller's
progress update for a manager or team.

## When to use it

Use it for weekly sales updates, sales progress decks, quarter-position
reviews, or summaries of committed deals. It covers work completed, deal
movement, pending outcomes, supported forecast position, and help needed.

## Before you start

Specify the reporting period, audience, and sales scope. Supply an export,
prior update, or preferred template where available, together with the
evidence you want reflected. Any forecast or quarter-position figures need
appropriate supporting inputs.

## Try it

> Refresh my weekly sales update from these notes and the prior deck. Carry
> forward unresolved actions and show where I need help.

## What you get

A concise summary and one editable progress update. A stuck-deal recap can
be included in the same artifact instead of becoming a separate document.

## Review and control

This is an individual Cowork skill. It does not convert suggestions into
commitments or discussions into decisions. Sending updates, changing CRM
records, and establishing recurring work require explicit user intent.
