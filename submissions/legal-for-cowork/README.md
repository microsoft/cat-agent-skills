# Legal for Cowork

A Microsoft-built Cowork plugin with twenty skills for understanding,
organizing, reviewing, editing, and preparing contracts and other legal
documents.

## What's included

| Area | Skills |
| --- | --- |
| Contract analysis | Analyze Related Contracts; Compare Key Terms; Review Contract; Summarize Redlines |
| Document checks | Check Cross-References; Check Defined Terms; Check Execution Readiness |
| Drafting and editing | Create Playbook; Draft New Contract; Draft Legal Memo; Draft Minutes and Resolutions; Edit Contract |
| Legal research and reasoning | Compare Across Jurisdictions; Explain Legal Concepts; Identify Regulatory Gaps; Legal Reasoning |
| Matter organization | Build Case Chronology; Extract Obligations and Deadlines; Summarize Legal Matters |
| Prompt preparation | Improve Legal Prompt |

## Before you start

Provide the documents or authorized sources to review, the question you want to
answer, and any relevant jurisdiction, review criteria, or approved playbook.
Share only material you are permitted to use for this task.

## Install

1. Download the plugin ZIP from this page.
2. Upload it through **M365 admin center > Manage apps > Upload custom app**,
   or sideload it for testing with the Microsoft 365 Agents Toolkit CLI:
   `atk install --file-path <zip> --scope Personal`.
3. Open **Cowork > Sources & Skills > Plugins** and enable it from **Discover**.

See [Get started with Cowork](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-cowork)
and [Build plugins for Copilot Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development).

## Limitations

Responses are generated by AI and may contain mistakes. Microsoft 365 Copilot
does not provide legal advice or replace qualified legal judgment.
Over-reliance on unverified outputs may create legal, commercial, or compliance
risk. You are responsible for verifying outputs before acting on them.
