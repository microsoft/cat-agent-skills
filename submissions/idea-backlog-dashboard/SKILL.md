Turn raw ideas, suggestions, or feedback into a clear backlog dashboard with priorities, owners, and recommended next actions.

## Instructions
1. Gather the ideas as a list or set of notes. If the user provides no structured details, infer the likely source, problem, and desired outcome from the text.
2. Normalize each idea into a consistent backlog item with:
   - title
   - source or trigger
   - summary
   - business value or user impact
   - effort or complexity
   - strategic fit or urgency
   - dependencies or risks
   - suggested owner or team
   - target status (backlog, ready, in progress, blocked, done)
3. Score each item using a simple prioritization model, such as:
   - impact / customer value
   - urgency / time sensitivity
   - effort / implementation cost
   - strategic alignment
   - risk / uncertainty
4. Rank ideas into priority buckets such as:
   - Immediate: high impact, low effort, or urgent dependency
   - Next: promising but needs validation or sequencing
   - Later: valuable but lower priority or resource constrained
   - Hold: low fit, unclear value, or deprioritized
5. Create a compact dashboard table or summary with columns like:
   - Priority
   - Idea
   - Value
   - Effort
   - Owner
   - Status
   - Notes / next action
6. Recommend a sequence of actions for the next sprint or planning cycle, including which items to validate, prototype, defer, or reject.
7. If the user asks for a report, produce a short executive summary, a prioritized list, and one or two decisions needed from stakeholders.

## Guardrails
- Do not invent facts or metrics that are not supported by the user input.
- Distinguish clearly between assumptions and confirmed information.
- Keep the backlog actionable; avoid vague entries like "improve experience" without specifying the outcome or stakeholder value.
- If the user is requesting brainstorming only, keep the output exploratory and label ideas as concepts rather than approved commitments.

## Tone
Use a practical, concise, and decision-oriented tone. Focus on clarity, prioritization, and momentum rather than generic brainstorming.
