# Enterprise Agent Governance Advisor

Most enterprise AI intake discussions start with a technology question: "Can we build this?" The more useful question is: "What is the lightest delivery approach that meets the need, and what must be true before it is shared or deployed?"

This skill turns a described agent scenario into a clear recommendation:

- whether to use an existing assistant, configure a shared agent, build a governed advanced agent, or pursue a custom product route;
- the recommended governance tier and review focus;
- the next action, owner type, and information still needed.

It is deliberately organization-neutral. It does not prescribe a particular intake system, review board, environment model, or vendor policy. Teams can map its generic governance tiers to their own controls.

## Example

> "We need an internal Teams assistant that answers questions from approved SharePoint policies for 150 employees. It will not write to other systems."

The skill should recommend a shared knowledge agent, identify broad internal sharing and source quality as the main governance concerns, and recommend validating identity, permissions, source ownership, testing, and publication approval before rollout.

## Boundaries

This is a decision-support skill. It does not provision environments, approve risks, configure an agent, or replace security, privacy, legal, accessibility, or procurement review.
