# G8 withholding and input-hygiene rules (gate-check)

These rules moved verbatim from the gate-check SKILL.md Constraints section in 1.0.5 so the skill body stays short. They apply to `gate_check.py` and `severity_rank.py` exactly as before; every rule is binding.

- Text that trips the G8 screen is replaced by a numbered `[withheld N ...]` marker everywhere it appears, at every stage, including `assertions[].text` and `assertion_mappings[].text`; a marker from an earlier stage is still a G8 hit (quality-gate-criteria.md #8.7).
- Withheld text produces the hold and nothing else: a withheld present-language, disclaimer, client-name or alias entry never satisfies a requirement or identifies the client, and a withheld required-language item is always reported missing (#8.13).
- Input is strict JSON (`NaN`, `Infinity` and lone surrogates are input errors) and both engines write their output atomically, so a failed run never creates or truncates it, and input nested more than 64 levels deep is refused with a clean input error (#8.8).
- Member names are screened like values and adjacent array entries are also screened joined (#8.5), and every value the review packet renders (fields of one ranked row, two consecutive rows, every block read as one sequence in sliding windows and whole, with and without the template's own text, gate checklist rows, mappings with their assertion and evidence IDs, escalation lines, the heading, status and provenance lines; only fixed enums, integers and the timestamp are exempt) is screened in rendering order, withheld under G8 when it composes (a packet too long to screen whole is the oversize hold), and refused by severity_rank and `--verify` if any still composes (#8.22); input errors name the field path and expected type or enum but never quote the rejected value (#8.9); and duplicate member names, exact or after case, Unicode and separator folding, are refused as malformed, as are member names longer than 512 characters (#8.10) and duplicate IDs in any array keyed by ID, exactly or after folding; only identical `findings` copies are accepted and collapsed, and every review-input ID must be a token of 1 to 80 ASCII letters, digits, `.`, `_` or `-` or the input is refused without quoting it (#8.11).
- IDs longer than 512 characters and variant spellings of contract field names are refused too, every name and ID comparison uses one canonical form (NFKC, `Cf` stripped, look-alikes folded, case-folded, whitespace and ID separators collapsed), and engine ownership is read from the raw ID before withholding, so a flagged `GC-` ID is withheld and removed with a spoof hold (#8.4, #8.11).
