# Representation menu

The idea catalogs for step 3, organized by **what's selected**. Read the section
for the selected element type; pull concrete options from it rather than recalling.
Every option is *a different way to make the same point land harder* — pick 3
genuinely distinct ones to build.

**Cross-cutting rule — push the narrative, don't rehash.** A winning idea makes the
point **clearer or more memorable** by adding *meaning*: a relatable comparison, a
benchmark, a surfaced insight, or the right visual form for the data. Re-typesetting
the same words in a nicer box, or swapping one neutral layout for another without
adding a comparison or takeaway, is a **rehash** — drop it. Even the "sharper text"
options below must sharpen to a *takeaway or insight* ("The West is carrying us"),
never just reword the same statement.

---

## A. Text is selected

Two families — offer a mix, not three of one.

**A1 · Sharper text** (still text, but it lands):
- **Takeaway rewrite** — restate a topic label as the point. "Q3 revenue" →
  "Q3 revenue jumped 40%." Say the conclusion, not the subject.
- **Cut to one line** — collapse a paragraph/bullet stack to a single sentence; the
  rest goes to speaker notes.
- **Pull the number out** — if a sentence hides a figure, promote the figure to a
  hero and demote the words to a caption.
- **Parallel + tighten** — make a list grammatically parallel and cut filler words
  (~40–70% shorter), so it scans.
- **Verb-first / active** — "There was a decrease in churn" → "Churn fell 55%."

**A2 · Replace the text with a visual** (the text becomes a picture of the idea):
- **List → structure** — 3 items → **pillars**; a sequence → **process/steps**;
  ~4 parallel items → **2×2 grid**; a hierarchy → nested blocks.
- **Stat → anchor visual** — a number → **scale anchor / competitive benchmark /
  rate / big-stat-with-meaning**. Use `anchor-library.md` for the figures and the
  anchor toolkit in `SKILL.md`.
- **Concept → analogy/metaphor image or icon row** — an abstract idea → a concrete
  visual (funnel, relay, iceberg) or an icon per point.
- **Comparison sentence → before/after cards or a small table.**

## B. A chart is selected

**B1 · A better-fit chart** (right chart for the data's job):
- **Trend over time** → **line** (not bars). Few series; label the last point.
- **Compare categories** → **horizontal bar**, sorted; not a pie.
- **Parts of a whole** → **bar or stacked bar**; use pie/doughnut only for ~2–3
  slices. Many slices → bar.
- **Correlation** → **scatter**.
- **One number that matters** → drop the chart; **big stat** callout.
- **Distribution** → histogram/box; **Progress to goal** → bullet bar or gauge-style
  single bar. Full chooser + gotchas in this file's tail.
- Simplify an overloaded chart: fewer series, direct labels, no chartjunk. (If they
  only want it *restyled*, say that is out of scope here — then offer to give it a point.)

**B2 · Replace the chart with an illustration** (when a chart is overkill):
- **Pictograph / isotype** — rows of repeated icons (1 icon = N units) for a single
  proportion or count; friendlier than a bar for a lay audience.
- **Big stat + icon** — one dominant number with a supporting icon, when the chart
  really carries just one figure.
- **Simple diagram** — flow, funnel, or map when the "chart" is really a process or
  geography.
- **Anchor visual** — the headline figure as a scale/benchmark/rate (see A2 / anchor
  toolkit).

## C. An image is selected

Diagnose whether the image is **decorative** (a stock photo filling space) or
**carrying information** (a screenshot, diagram, or photo of a real thing). Ask only
when the slide and notes genuinely do not reveal which role it serves.

- **Decorative photo → explanatory visual** — replace with a **diagram**, **icon
  set**, or **data visual** that actually conveys the slide's point.
- **Image hiding data → chart or pictograph** — if the picture is standing in for
  numbers, show the numbers (see B).
- **Concept photo → metaphor illustration or icon** — a cleaner, on-brand visual
  that reads instantly at a glance.
- **Busy image → single focal visual** — one clear icon/diagram beats a cluttered
  photo; let size + whitespace do the work.
- **Keep-but-reframe** — sometimes the image is fine and the fix is a **takeaway
  caption/overlay**; offer that as one option when replacement isn't warranted.

## D. Nothing selected, or the user made a statement about the slide

Treat it as **whole-slide ideation**: find the slide's single point (title + text +
notes + data) and offer 3 directions that make *that* land — usually the A2 visual
menu and the anchor toolkit. This is the classic behavior; `worked-examples.md`
covers it.

## Chart chooser (quick reference for B1)

| The data's job | Default chart | Avoid |
|---|---|---|
| Change over time | Line (few series) | 3-D anything, many bars |
| Rank / compare categories | Horizontal bar, sorted | Pie |
| Parts of a whole (2–3 parts) | Bar; pie only if ~2–3 | Pie with >4 slices |
| Parts of a whole (many) | Stacked/100% bar | Multi-slice pie |
| Correlation | Scatter | Dual-axis lines |
| One key number | Big stat callout | A chart at all |
| Progress to a target | Single bar vs target line | Gauge clutter |
| Composition over time | Stacked area (few bands) | Spaghetti lines |

Rules of thumb: sort bars by value; label directly instead of using a legend when
there are ≤4 series; never a second Y-axis if a ratio or index would do; keep to one
message per chart.

## Illustration types (quick reference for A2 / B2 / C)

Icon (one concept) · icon row (parallel points) · pictograph/isotype (proportion) ·
diagram/flow (process) · funnel (stages) · map (geography) · metaphor image (abstract
idea) · timeline (sequence) · comparison cards (before/after, us/them) · big-stat +
icon (one number) · **detailed silhouette/scene** (a place, object, or creature the
stat is compared to).

**Make illustrations rich, and match the deck.** When the idea calls for a picture of
a *thing* — a skyline, a landmark, an elephant, a stadium — either **generate an
image** (if a tool is available) or **build a detailed vector silhouette** from many
shapes, in the deck's palette, line weights, and flat-vs-shadowed style. A lone
rectangle or single circle standing in for "Paris" is a basic-shape failure, not an
illustration. Keep charts/diagrams native and editable; reach for a real depiction
(generated or richly drawn) when the comparison is pictorial. See
`build-recipes.md` §3 for the rung order.
