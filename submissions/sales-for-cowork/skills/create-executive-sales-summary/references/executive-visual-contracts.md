# Executive evidence relations
Optional under user/host design. Select by the question; no fixed proportions, palette or page skeleton. Keep essential data/state bindings, remove lookup/prose that repeats the exhibit.

## forecast-conditions
Compare compatible metrics/horizons on a common axis with target and actual-to-date labeled separately. Bind each scenario's condition/evidence/state by ID beside its mark. Use one subtraction convention for gap label/geometry; never stack overlapping scenarios. Incompatible measures need separate comparisons. Fail: invented probability, detached conditions or all meaning in a paragraph beside a mute chart.

## decision-tradeoff
Use only supplied choices/consequences. Make the decision and approval state clear with comparable criteria/units, then owner/timing. Unknowns remain unknown. An open conclusion may suffice; enclose only a real option/scope, and connect only a real branch. Fail: arbitrary scores/checkmarks, invented alternative or styling a recommendation as approved. Without supported choices show the question/evidence needed.

## contribution-bridge
Use a bridge only when opening plus signed drivers equals closing; otherwise show partial signed contributions. Derive components/endpoints from one measure/subtraction convention; formula, printed sign, geometry and total must agree. Totals start at zero; floating spans use computed cumulative endpoints. Keep a common scale, no minimum-height clamps. Tiny effects get direct labels/leaders; regroup additive categories only. Positive shortfall magnitudes need explicit labels separate from signed variance. Fail: residual omitted, overlapping drivers, unbound bar nudges, rates ranked as absolute contributions or unsupported causes.
