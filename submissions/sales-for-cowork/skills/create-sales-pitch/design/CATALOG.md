# Sales design catalog

| ID | File | Use |
|---|---|---|
| evidence-led | `create-sales-pitch/design/evidence-led.md` | Open editorial evidence, related Blue/Cyan accents and native components |

Use `../narrative.md`'s `default_design` unless the user requests another design. A compatible
user brand/style wins; retain normal confirmation and provider gates. Read the
selected design and `evidence-led.tokens.json` completely, then `patterns.md` to select
one recognizable hierarchy per page. Finish truncated reads before authoring;
opening this catalog alone does not load those files. `layouts.md` supplies aspect suitability;
the selected design and composition pattern supply emphasis.

Use the selected design only where permitted by the current workflow, as defaults
for unspecified typography, color, surfaces and media. Live/reading mode and
density are independent of palette. Do not reopen resolved generic style discovery.
User-selected brand/style governs fonts, palette and surfaces; tokens supply
fallback roles, not permission to overwrite that choice.
