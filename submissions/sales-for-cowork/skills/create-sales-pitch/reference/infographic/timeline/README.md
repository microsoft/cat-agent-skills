# Milestone spine

Asset: `create-sales-pitch/reference/infographic/timeline/icon-phases.pptx`.
Use for 3–6 meaningful ordered events, usually company/capability history.

Preserve circular nodes, meaningful icons and order along one continuous thin
spine crossing node centers. Keep dates above and event captions below, with a
coherent Blue/Cyan progression and icon ink suited to each node. The native rail
has a continuous gradient; do not replace it with disconnected accent dashes.

Use actual dates and captions. Spacing is categorical, not elapsed-time scale.
Reflow actual counts, use two rows or a vertical arrangement when necessary, and
keep round geometry/constant icon proportions. Captions remain ordinary text.
No-icon restrictions remove icons throughout and require an explicit compatible
adaptation, not a claim of icon-bearing identity.

For grouped execution with input/action/output and human gates, prefer
`create-sales-pitch/reference/infographic/process/three-stations.pptx`.
