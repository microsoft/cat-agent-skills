- **Use:** distinct supported peer capabilities, applications or actions. Position
  does not establish order, rank, causation or equal impact.
- **Adapt:** actual count, open rows or cards, dimensions, emphasis and useful
  short value descriptions. No fixed four-card layout or filler in an empty region.
- **Preserve:** peer meaning, label/icon pairing and a coherent visual family.
  Retained ordinary cards follow the selected design's corner/border language.
- **Data/media:** choose sourced semantic icons for actual concepts, respecting
  `../../../SKILL.md`'s restrictions. Reflow in the correct parent coordinate system;
  group-child offsets are not slide offsets.
