# Partition ring

Asset: `create-sales-pitch/reference/infographic/allocation/partition-ring.pptx`.
Use for an exhaustive, mutually exclusive whole: a study partition, budget or
proposed allocation. Never use overlapping groups directly as sectors.

The native doughnut is linked to an embedded workbook. Preserve the substantial
ring, centered total and associated category/count/share labels. The sample
40/30/20/10 counts total 100 units; they are placeholders, not business evidence.
`PARTITION_CHART` owns sector geometry; `PARTITION_TOTAL` is the editable center.

Replace categories and values through native chart data, updating workbook,
caches, labels, total and percentages together. Shares equal count / total and
sectors use those same nonnegative values. A zero total cannot define a share;
use a non-quantitative alternative. Keep units, denominator, scope and proposal
status visible. Use related shades and neutral Others only when semantically
appropriate. Reflow labels rather than stretch the ring or hide small sectors.
