# People and roles

Asset: `create-sales-pitch/reference/infographic/team/portrait-cards.pptx`.

- **Use:** supplied people/roles whose experience matters to the decision.
  A proposed role is not a hired person; a workstream is not an employee.
- **Adapt:** actual count, portrait/description balance, open rows or cards,
  and useful responsibilities. Never invent identities to occupy the five frames.
- **Preserve:** person-to-role pairing, equal-rank meaning, consistent crop and
  the selected design's ordinary image/card treatment.
- **Data/media:** actual people need authorized matching photos, not generated
  stand-ins, anonymous colleagues or a different person's portrait. Follow the
  design's image-identity and placement rules; no portraits are packaged.

For missing authorized images or user restrictions, use an appropriate native
role/evidence view without empty reservations; do not misrepresent it as a
completed portrait layout. Do not fabricate names, credentials or endorsements.
Source identity is recorded in `../manifest.json`.
