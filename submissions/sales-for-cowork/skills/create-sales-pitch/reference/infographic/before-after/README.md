# Paired transformation rails

Asset: `create-sales-pitch/reference/infographic/before-after/paired-state-rows.pptx`.
Use for matched concerns in current/desired or before/after states.

Keep tapered left/right rails aligned row by row, their pointed ends meeting at
the central seam, with ordinal markers near the outer ends. These are comparisons,
not five sequential steps or measured bar widths. Replace headers and labels,
reflow 3–5 supported pairs and recolor through the selected theme. Do not add
decorative card frames.

Each row must compare the same concern. A desired outcome is a proposal unless
achieved evidence is supplied. Use concise editable labels at the ordinary-text
floor; move longer descriptions outside the rails before shrinking the diagram.
