# Schematic stage funnel

Asset: `create-sales-pitch/reference/infographic/funnel/icon-stages.pptx`.
Its stable ID does not imply the specimen contains icons.

- **Use:** meaningful narrowing stages, such as actual acquisition/conversion
  evidence, not a mandatory GTM chapter. Counts need one cohort/time window,
  deduplication rule, population and explicit denominators.
- **Adapt:** real stage count, readable stage/count/rate space and whole-group
  composition. Preserve meaningful labels without filling extra stages.
- **Preserve:** centered separated equal-height tapered bands and the schematic
  convention. Width represents stage order, not quantity or retention ratio.
  When showing counts/rates, visibly identify the widths as schematic and not
  proportional; correct numbers alone do not explain the geometry.
- **Recompute:** counts, adjacent rates and separate overall conversion from
  the actual data. Adjacent rates use the prior stage; overall uses the entering
  population. Zero is zero; conversion from a zero denominator is undefined.

For quantity-proportional geometry, derive dimensions from actual quantities on a
common scale, such as zero-based bars, rather than arbitrary tapering. Unknown
counts do not imply equal conversions. Unordered channels belong in List;
no decorative icons/photos are needed. Source is in `../manifest.json`.
