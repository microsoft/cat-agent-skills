# Workstream rails

Asset: `create-sales-pitch/reference/infographic/gantt/workstream-rails.pptx`.

- **Use:** actual parallel tasks with a shared time basis, inclusive starts/ends,
  state, and sourced dependencies/gates. Not a routine first-customer CTA page.
- **Adapt:** task count, label widths/heights, supporting condition space and
  axis labels. Use a clear shared unit/origin; no joined tick labels or overlapping
  owners. Empty specimen lanes do not justify invented tasks.
- **Preserve:** one time scale, capsule rails/bars, common axis, exact duration
  edges, parallel meaning and gate endpoints. Capsules are semantic time marks,
  not ordinary cards.
- **Recompute:** inclusive duration is end - start + 1; M1-M6 is six periods.
  Gate markers align with their actual period boundary, not a visually convenient
  next-period center. Keep full acceptance conditions and permitted early
  experiments visible. Never lengthen bars to fill whitespace.

Continuous dates require an explicit continuous scale; milestones are points.
Undated ordered steps use Timeline, unordered proposals use List. Photos and
routine icons are unnecessary. Source and native roles are in `../manifest.json`.
