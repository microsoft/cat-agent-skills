# Four semantic quadrants

Asset: `create-sales-pitch/reference/infographic/swot/four-quadrants.pptx`.

- **Use:** scoped internal strengths/weaknesses and external opportunities/threats
  when strategic diagnosis helps the decision, not a default pitch chapter.
- **Adapt:** evidence-backed entry counts, label/description space and emphasis.
  Do not manufacture an item to fill every region.
- **Preserve:** four semantic categories, S/W versus O/T pairing, chamfered polygons
  and corresponding callouts. These are not ordinary rounded cards.
- **Data/media:** distinguish findings, hypotheses and proposed responses.
  Letters/headings identify the categories; icons must not compete with them.
  A focused risk/opportunity view is preferable to an unhelpful full SWOT.
