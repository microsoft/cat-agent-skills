# Two-set overlap

Asset: `create-sales-pitch/reference/infographic/venn/two-set-overlap.pptx`.

- **Use:** two defined sets with supported intersection and exclusive properties.
  Do not infer synergy or market size from overlapping circles.
- **Adapt:** useful set descriptions, label positions and uniform scale.
  Create/reflow every required text line rather than assigning only existing runs.
- **Preserve:** circles, lens, boundaries and set/region correspondence.
  Use fills, opacity and stacking that keep the intersection distinct from both
  exclusive regions. This is a qualitative composition, not an area-proportional
  chart.
- **Data:** whole-set totals are not exclusive-region counts. Label totals outside
  the crescents or explicitly as totals; set-minus-overlap belongs in exclusive
  regions and overlap in the lens. Keep definitions/population clear.

Without counts use supported properties; without an established intersection,
use a comparison/List instead. Quantitative set areas require an honest separate
calculation, not stretched donor circles. No imagery is required. Source identity
is recorded in `../manifest.json`.
