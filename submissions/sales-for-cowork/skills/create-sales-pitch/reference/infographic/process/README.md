# Three-station process

Asset: `create-sales-pitch/reference/infographic/process/three-stations.pptx`.
Use for an input/action/output overview with short editable descriptions.

Keep three stations on one baseline and two solid native right arrows between
them. The arrows indicate direction, not chevrons, time intervals or attrition.
Ordinal numbers identify stages; they are not semantic icons.

Group detailed actions under the stations only if all material work and human
gates survive: approved inputs and outline, editable production, evidence/revision
and final human release. Use supplied phase names; remove irrelevant sample
content. Equal spacing does not claim equal duration or automatic correctness.
Reflow descriptions at the ordinary-text floor without boxing every station.
