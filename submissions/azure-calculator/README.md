# Azure Calculator

Produces traceable Azure cost estimates: from requirements gathering through architecture proposal and service bill of materials to monthly and annual costs, using current list prices from the public Azure Retail Prices API (no app registration needed).

**What the skill delivers**
- Executive summary, assumptions, architecture, bill of materials, cost overview
- Scenarios (minimal / base / growth) and FinOps recommendations
- Status per line item: verified, derived, assumption, open
- Optional JSON or CSV output

**Example prompts**
- "What does a web app with Azure SQL and 2 TB of Blob Storage in West Europe cost?"
- "Create an Azure TCO estimate with three scenarios as CSV."

**Note:** Results are based on public retail prices and are not a binding quote.
