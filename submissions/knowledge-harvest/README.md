# Knowledge Harvest

A Microsoft-built Agent Skill for Cowork that turns a verified support
resolution or workaround into reusable knowledge for review.

## When to use it

Use it after a case is resolved or a workaround has been verified. It helps
draft a knowledge article, assess overlap with existing guidance, and identify
recurrence-prevention actions. It is not a tool for answering a current
customer question or publishing unresolved speculation.

## Before you start

Provide the resolution evidence, symptoms, cause, workaround or fix, and the
scope in which it was tested. Include existing guidance to compare against
and the intended review audience. Remove unnecessary identifying information.

## Try it

> Turn this verified resolution into a draft knowledge article. Separate
> symptoms, cause, fix, and tested scope, and check for overlap with the
> attached guidance.

## What you get

One editable review artifact and a brief chat summary with its link. A supported,
authorized CRM review record is preferred; Word or Markdown can be used when
CRM saving is unavailable. The skill reports the actual save destination and
any fallback.

## Review and control

This is an individual Cowork skill. Customer-identifying details should be
removed. A draft article or case note is not published guidance. Publication,
sharing, and changes to underlying records require separate authorization.
