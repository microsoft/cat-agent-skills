# Education for Cowork

A Microsoft-built Cowork plugin with ten skills for the work that repeats each
term: teaching support, institutional governance, evidence gathering, and
staff communications.

## What's included

| Skill | Workflow |
| --- | --- |
| Accessible Learning Materials | Accessibility reviews of learning materials |
| AI Rollout for Education | Staff AI adoption and rollout planning |
| Discussion Insights for Education | Insights from course discussions |
| Evidence Package for Education | Accreditation and review evidence packages |
| Governance Review for Education | Institutional governance reviews |
| Instructional Continuity | Substitute and continuity packs |
| Instructional Retrospective | Course and teaching retrospectives |
| Policy Change Pack for Education | Policy rollout materials |
| Research Project Brief | Research project briefs |
| Weekly Brief for Education | Recurring education-team briefs |

## Before you start

Identify the course, team, institution, or project you want to work on. Provide
the relevant materials and intended audience, or make authorized sources
available in Cowork. Avoid including student or staff information that is not
needed for the task.

## Try it

> Review these learning materials for accessibility and identify changes we
> should consider.

> Prepare a policy rollout pack using the attached policy and implementation
> notes. Flag missing information.

## Install

1. Download the plugin ZIP from this page.
2. Upload it through **M365 admin center > Manage apps > Upload custom app**,
   or sideload it for testing with the Microsoft 365 Agents Toolkit CLI:
   `atk install --file-path <zip> --scope Personal`.
3. Open **Cowork > Sources & Skills > Plugins** and enable it from **Discover**.

See [Get started with Cowork](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-cowork)
and [Build plugins for Copilot Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development).

## Review before use

Outputs depend on the materials and tools available to Cowork. Review generated
content before using it for teaching, governance, or institutional decisions.
This plugin runs in Cowork; it is not a standalone Copilot Studio skill.
