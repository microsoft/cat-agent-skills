# Vendor Review Rules (cited as vendor-review-rules.md #<n>; engine constants mirror sections)
## 1. Scorecard integrity
1.1 OTIF = lines delivered on time AND in full / total lines, per quarter, from receipts vs PO dates. Computed, never taken from the vendor's own deck.
1.2 A metric declining across >= 3 consecutive quarters is a TREND FLAG regardless of the latest absolute value.
## 2. Clustering
2.1 Issues cluster by type x lane/DC; a cluster needs >= 3 occurrences with record ids as evidence.
## 3. Terms
3.1 Every scorecard breach maps to the governing term clause; a breach without a retrieved clause is an open item, not a talking point.
3.2 Term-triggered remedies (rebates, corrective action rights) are stated with the clause quoted - invoking them is the buyer's decision.
## 4. Conduct
4.1 Relationship quality, hospitality and pricing goodwill are not scorecard inputs. The pack reports records.
## 5. Confidence floor
Missing receipts or terms -> confidence < 0.75; the affected section is marked incomplete.
