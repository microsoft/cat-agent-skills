# Mapping conventions

- Rounded rectangle: task
- Diamond: decision
- Circle: start or end
- Solid arrow: normal process flow
- Dashed arrow: exception or return path
- Lanes are represented by owner labels and color bands in the generated map.
- Step IDs must be stable so the SOP, process map, RACI, controls, and backlog can cross-reference each other.
- Avoid more than 25 steps in one map. Split into subprocesses when necessary.
