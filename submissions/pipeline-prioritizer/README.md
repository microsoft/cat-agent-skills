# Pipeline Prioritizer

A Microsoft-built Agent Skill for Cowork that ranks open opportunities into
an evidence-backed worklist.

## When to use it

Use it to decide which deals to work on next and why. It supports ties and
bounded assessments when the evidence does not justify a precise ranking.
For a digest of what changed, use Deal Catch-up instead.

## Before you start

Specify the deals or portfolio and provide the visible opportunity set,
relevant constraints, and recent evidence. Include your organization's
priority criteria where available. Connected CRM can enrich the assessment,
but unsupported facts should remain unknown.

## Try it

> Prioritize these open opportunities for today's work. Explain the ranking,
> allow ties, and identify what information could change the order.

## What you get

A concise summary and one editable worklist with ranked or tied opportunities,
supporting evidence, proposed next moves, and uncertainty.

## Review and control

This is an individual Cowork skill. Deal value, staleness, and risk are
inputs, not automatic rankings. The skill does not make CRM changes or
contact customers merely because it recommends a next action.
