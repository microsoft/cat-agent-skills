# Qualification Rules (cited as qualification-rules.md #<n>; engine constants mirror sections)
## 1. Certification validity
1.1 ISO 9001 / IATF cert must be CURRENT (expiry >= as-of date). Expired cert -> quality band HIGH risk + escalation; a cert on file is not a cert in force.
## 2. Financial floor
2.1 Quick ratio < 1.0 -> financial risk elevated one band. 2.2 Declining trend across periods -> +1 band. 2.3 Below 0.8 with declining trend -> HIGH.
## 3. Geographic concentration
3.1 If >= 60% of category spend is already in the candidate's region, geographic risk is elevated - qualification must not deepen concentration without a dual-source plan.
## 4. PPAP completeness
4.1 Required elements per category (min: PSW, control plan, process FMEA, MSA). Any missing element -> conditional at best, with the element as a named condition.
## 5. Recommendation bands
low -> qualify · moderate -> conditional (named conditions) · high -> do_not_qualify unless the commodity council overrides in writing.
## 6. Confidence floor
Missing financials or unverifiable cert -> confidence < 0.75, human sourcing review required.
