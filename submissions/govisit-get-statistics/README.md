# GoVisit: Get Statistics

Use when an agent needs exact GoVisit catalog coverage counts for the physical World or a selected Destination, with observation dates and provenance.

This Agent Skill teaches an agent to call GoVisit's public, read-only travel data tools over HTTPS. The bundled `SKILL.md` includes the invocation guidance; `references/contract.json` describes the tool's input and output. No API key is required.
