# RCA Methods (grounding for root-cause-analyze; ISO 9001 10.2, 8D D4)
- Pareto: rank cause categories by frequency over the complaint window; the top category is the entry point, not the conclusion.
- 5-Why: chain from the defect to a process/system cause; each "why" must be evidenced in the record set (complaint rows, calibration logs, tool-life data), not asserted.
- Systemic test: a cause appearing across >= 2 part numbers or >= 2 machines is systemic (drives capa-rules.md #5).
- 8D mapping: D2 problem = NCR facts; D3 containment; D4 root cause (this analysis); D5/D6 CA; D7 PA; D8 closure.
