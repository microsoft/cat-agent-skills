# Work-order draft structure reference — not a fillable template

Only scripts/render_writeup.py produces the report after recomputing the evidence.
It renders one fixed Markdown (.md) draft for technician/planner review, not separate
audience voices. Do not fill tokens, add model-authored sections, invent cost/priority
framing or use this reference for document conversion.

The runtime layout contains work-order/asset context; issue and cited SOP; open
escalations; recomputed similar work; recomputed parts snapshot; draft proposed next
action; review/handoff; and the recomputed contract appendix. Unknowns remain
unverified. Scores are not repair-success probabilities.

No stock reservation, expedite, scheduling, assignment, purchasing, CMMS update,
closure or repair authorization is performed or inferred, even after approval.
Qualified humans review physical stock, engineering guidance and safety procedures
outside the plugin. For unsupported formats or audience-specific transformations,
explain the limitation and ask whether the existing fixed Markdown draft is acceptable.
