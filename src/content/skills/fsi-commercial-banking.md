Six skills for commercial banking credit and coverage teams. Build a standalone historical borrower-credit spread with source assurance/basis, visible normalization, five-check extraction verification, and live credit ratios in Input, Normalized, and Ratios tabs. Draft descriptive credit-memo sections. Assemble annual credit-monitoring packets with explicit comparison limits. Perform separate governing-agreement/amendment-led covenant and borrowing-base reviews with verified inputs, states, and flags. Research borrower/prospect public records. Prepare named external borrower/prospect relationship calls and write up supplied call notes. Integrated three-statement model completion, including historical population and embedded covenant schedules, internal operating/forecast review prep, and standalone stakeholder Q&A are outside this plugin. Runs without a paid subscription or Finance-plugin dependency, using supplied documents, Microsoft 365, public registries, SEC EDGAR, and public web. Scanned and photographed statements are read directly; unreadable figures are marked, never estimated. Loan origination, core banking, CRM, business credit, and benchmark connectors enrich sources without expanding scope; templates change the credit schema or layout, not workflow ownership. Every figure carries its source and page. The skills never rate a credit, approve or decline, set pricing, draft adverse-action reasons, or characterise creditworthiness.

> **Cowork plugin.** This is a Microsoft 365 Copilot **Cowork** app package (a `.zip` bundling the skills and connectors below). It installs on Cowork only.

## Skills in this plugin

- **financial-statement-spread** — Build a standalone historical borrower-credit spread with assurance/basis, extraction checks, visible normalization, and live ratios in Input, Normalized, and Ratios tabs. Use when the user says "spread this borrower's statements", "build a credit spread from this tax return", "normalize these borrower financials", "show this borrower's historical coverage", or "use our credit-spread template". Do NOT use for integrated-model population or forecast links — use Finance 3-statements if available instead. Do NOT use for agreement-led tests — use covenant-compliance-check instead. Do NOT use for annual packets — use credit-annual-review-packet instead. Do NOT use for memo narrative — use credit-memo-narrative instead. Do NOT use for workbook formatting — use xlsx instead.
- **credit-memo-narrative** — Draft sourced descriptive credit-memo sections for a new-money, increase, or renewal request; recap only supplied financials. Leave rating, recommendation, and conditions to the banker. Use when the user says "write up this credit request", "draft the memo narrative", "start the approval package", "write the business description for this deal", or "draft the industry section". Do NOT use for spreads — use financial-statement-spread instead. Do NOT use for periodic monitoring — use credit-annual-review-packet instead. Do NOT use for standalone covenant tests — use covenant-compliance-check instead. Do NOT use for company background alone — use borrower-prospect-research instead. Do NOT use for document formatting — use docx instead.
- **credit-annual-review-packet** — Assemble a periodic credit-monitoring packet with no live transaction: prior/current financial comparison, covenant status, exceptions, public-record refresh, and factual changes. Leave rating and conclusion to the analyst. Use when the user says "put together the annual review", "build the credit monitoring review", "what changed on this credit since last year", "assemble the portfolio review packet", or "this borrower's annual is due". Do NOT use for new-money or renewal memos — use credit-memo-narrative instead. Do NOT use for standalone covenant tests — use covenant-compliance-check instead. Do NOT use for company background alone — use borrower-prospect-research instead. Do NOT use for document formatting — use docx instead.
- **covenant-compliance-check** — Perform a standalone agreement-led covenant or borrowing-base review using amendments, defined terms, test dates, verified inputs, exclusive states, and independent flags. Use when the user says "check this agreement's covenants", "verify this compliance certificate", "show leverage-covenant headroom", "test the springing covenant", or "review the borrowing base". Do NOT use for integrated-model completion or its embedded covenant tab — use Finance 3-statements if available instead. Do NOT use for historical spreads — use financial-statement-spread instead. Do NOT use for memo narrative — use credit-memo-narrative instead. Do NOT use for workbook formatting — use xlsx instead.
- **borrower-prospect-research** — Build a sourced public-record background brief on a commercial borrower or prospect, with entity identity, jurisdiction, retrieval date, and search limits. Use when the user says "what do we know about this company", "run background on this borrower", "pull public records on Acme", "who owns this business", or "any liens or litigation on this prospect". Do NOT use for financial spreads — use financial-statement-spread instead. Do NOT use for relationship-history call prep — use rm-call-prep-followup instead. Do NOT use for standalone covenant tests — use covenant-compliance-check instead. Do NOT use for document formatting — use docx instead.
- **rm-call-prep-followup** — Prepare an external commercial borrower/prospect relationship call from contact history, or write a memo and draft follow-up from supplied call notes. No terms, pricing, appetite, or commitments. Use when the user says "prep my borrower call", "what do we owe this borrower", "write up this borrower call", "draft the borrower follow-up", or "what did I commit to this client". Do NOT use for internal operating/forecast reviews — use Finance forecast-review-prep if available instead. Do NOT use for standalone stakeholder Q&A — use Finance stakeholder-qa-prep if available instead. Do NOT use for company research alone — use borrower-prospect-research instead. Do NOT use for generic transcript summaries — use meeting-intel instead. Do NOT use for email operations — use outlook-email instead.

## Install

1. Download the plugin package (the `.zip` on this page).
2. Upload it to your tenant via **M365 admin center › Manage apps › Upload custom app**, or sideload it for testing with the [Microsoft 365 Agents Toolkit CLI](https://learn.microsoft.com/en-us/microsoftteams/platform/toolkit/microsoft-365-agents-toolkit-cli) (`atk install --file-path <zip> --scope Personal`).
3. Open **Cowork › Sources & Skills › Plugins** and enable it from the **Discover** section.

See [Build plugins for Copilot Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development) for details.
