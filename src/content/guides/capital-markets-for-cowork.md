# Capital Markets for Cowork

A Microsoft-built Cowork plugin with ten skills supporting analyst work in
banking, investment research, and private equity.

## What's included

| Skill | Workflow |
| --- | --- |
| CIM Teardown | Review a confidential information memorandum |
| Company Profile Pack | Prepare a source-backed company profile |
| Comps Analysis | Comparable company analysis |
| Coverage Meeting Prep and Debrief | Prepare for and capture coverage meetings |
| Due Diligence Checklist | Build and track diligence questions |
| Document Diligence | Review diligence documents |
| Earnings Note | Prepare an earnings note |
| Investment Committee Memo | Draft an investment committee memo |
| Merger Model | Merger modeling |
| Pitch Deck Skeleton | Outline a pitch deck |

## Before you start

Identify the company, transaction, or research scope and the output you need.
Provide source documents, relevant dates, and any required templates or
assumptions. Use only material you are authorized to access.

## Try it

> Build a company profile pack from these documents, including source dates
> and unanswered questions.

> Draft an investment committee memo using the supplied diligence materials.
> Separate supported findings from assumptions.

## Install

1. Download the plugin ZIP from this page.
2. Upload it through **M365 admin center > Manage apps > Upload custom app**,
   or sideload it for testing with the Microsoft 365 Agents Toolkit CLI:
   `atk install --file-path <zip> --scope Personal`.
3. Open **Cowork > Sources & Skills > Plugins** and enable it from **Discover**.

See [Get started with Cowork](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-cowork)
and [Build plugins for Copilot Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development).

## Limitations

The skills provide analytical support, not advice. Outputs state their sources
and dates and mark assumptions rather than inventing missing facts. Nothing is
sent or shared without your confirmation. Review all analysis and calculations
before relying on them.
