# Accounting for Cowork

**Availability: Frontier only for now.**

Helps company accounting professionals reconcile accounts, prepare journal
entries, analyze variances, and report results. The plugin bundles seven skills
for accounting workflows, financial statements, financial presentations,
reconciliation, journal entries, budgets and forecasts, and tax preparation.

Responses are generated by AI and may contain mistakes. Skills are optimized
for ENUS. Microsoft 365 Copilot does not replace qualified accounting judgment.
You are solely responsible for verifying any output before acting on it.

## Install

1. Download the plugin ZIP from this page.
2. Upload it through **M365 admin center > Manage apps > Upload custom app**,
   or sideload it for testing with the Microsoft 365 Agents Toolkit CLI:
   `atk install --file-path <zip> --scope Personal`.
3. Open **Cowork > Sources & Skills > Plugins** and enable it from **Discover**.

See [Get started with Cowork](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-cowork)
and [Build plugins for Copilot Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development).
