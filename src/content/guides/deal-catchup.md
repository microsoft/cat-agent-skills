# Deal Catch-up

A Microsoft-built Agent Skill for Cowork that summarizes what changed across
a scoped deal set and explains the evidence behind that movement.

## When to use it

Use it after time away, before a review, or when you need a digest of deal
changes since a baseline. It separates genuine customer movement from record
housekeeping. Use Pipeline Prioritizer instead when the question is what to
work on next.

## Before you start

Name the account, deals, or portfolio and the comparison period. Supply
current evidence and, if available, an earlier snapshot or prior update.
Without a baseline, the skill can report current state while marking change
as unknown.

## Try it

> Catch me up on these deals since last week's review. Explain supported
> changes and flag reasons we have not confirmed.

## What you get

A concise chat summary and one editable change digest showing current state,
supported movement, reasons, and missing or unconfirmed evidence.

## Review and control

This is an individual Cowork skill. A record-modification timestamp alone is
not proof of a deal change. The digest is read-only apart from saving the
requested artifact; it does not update deals or contact customers.
