# MCT Excellence IQ

> **An AI-powered Instructional Excellence Intelligence Skill for Microsoft Certified Trainers.**

MCT Excellence IQ is an enterprise-grade AI Skill for Microsoft Copilot Studio and Microsoft Cowork that empowers Microsoft Certified Trainers (MCTs) to design, prepare, deliver, evaluate, and continuously improve world-class Microsoft learning experiences.

It combines instructional design, Microsoft technical expertise, adaptive teaching, multilingual learning, learner assessment, survey intelligence, and responsible AI into a single teaching companion.

---

## Vision

Empower every Microsoft Certified Trainer with AI to create engaging, practical, inclusive, and enterprise-ready learning experiences.
