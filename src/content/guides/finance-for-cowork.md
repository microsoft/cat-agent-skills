# Finance for Cowork

A Microsoft-built Cowork plugin with thirteen skills for finance close,
planning, review preparation, evidence gathering, and financial modeling.

## What's included

| Skill | Workflow |
| --- | --- |
| Three Statements | Complete existing income statement, balance sheet, and cash flow model templates |
| Audit Evidence Package | Assemble reviewable audit evidence |
| Budget Consolidation | Consolidate budget inputs |
| Close Status Digest | Summarize close status |
| Dataset Analysis Report | Analyze a supplied dataset |
| DCF Valuation | Discounted cash flow modeling |
| Expense Itemization | Itemize and reconcile expenses |
| Executive Update | Prepare executive finance updates |
| Forecast Review Prep | Prepare for forecast reviews |
| LBO Model | Leveraged buyout returns modeling |
| Quarterly Workback | Build quarterly work-back plans |
| Stakeholder Q&A Prep | Prepare for stakeholder questions |
| Variance Commentary | Explain financial variances |

## Before you start

Specify the reporting period, organization or business scope, and intended
audience. Provide the relevant files, model templates, or authorized sources.
For quantitative work, include units, currencies, periods, and the assumptions
you want used.

## Try it

> Prepare a close-status digest from these updates, separating completed work,
> blockers, and missing evidence.

> Complete this existing three-statement model using the supplied inputs.
> Explain the sources and assumptions.

## Install

1. Download the plugin ZIP from this page.
2. Upload it through **M365 admin center > Manage apps > Upload custom app**,
   or sideload it for testing with the Microsoft 365 Agents Toolkit CLI:
   `atk install --file-path <zip> --scope Personal`.
3. Open **Cowork > Sources & Skills > Plugins** and enable it from **Discover**.

See [Get started with Cowork](https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-cowork)
and [Build plugins for Copilot Cowork](https://learn.microsoft.com/en-us/microsoft-365/copilot/cowork/cowork-plugin-development).

## Review and control

The skills show sources and mark missing information rather than guessing.
They do not send email or calendar invitations without your confirmation.
Review calculations, assumptions, and source dates before using the outputs
in financial decisions.
