# Case Triage

A Microsoft-built Agent Skill for Cowork that prioritizes support issues using
impact, deadlines, commitments, and evidenced urgency.

## When to use it

Use it to compare tickets, incidents, requests, or complaints and explain which
should be worked first. It can also assess the bounded urgency of one issue,
without inventing a queue position.

## Before you start

Provide the issues to compare and the facts available for each. Include
impact, deadlines, commitments, response-time evidence, and your organization's
priority criteria where known. Missing information should remain explicit.

## Try it

> Rank these support issues for today's work. Explain the priority drivers,
> allow ties, and flag information that could change the order.

## What you get

For several issues, a concise summary and one editable triage result.
For a single issue, an urgency assessment in chat by default; a saved artifact
is created only when requested.

## Review and control

This is an individual Cowork skill. Age or emotional tone alone is not a
confirmed response-time breach. The skill does not claim work, change
priority fields, reassign issues, or close cases merely by recommending
an order.
