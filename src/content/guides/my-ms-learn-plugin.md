# My MS Learn Plugin

Bring official Microsoft documentation straight into Copilot Cowork.

When you ask about a Microsoft product, service, API, or best practice, Cowork
uses this plugin to search **Microsoft Learn** and answer from the official,
up-to-date docs, with links back to the source.

## What's inside

A single connector to the official
[Microsoft Learn MCP server](https://learn.microsoft.com/api/mcp). No sign-in
or API key needed.

## Try asking

- "What's the recommended way to authenticate to Azure Storage from Python?"
- "How do I add a knowledge source to a Copilot Studio agent?"
- "What are the Microsoft Graph permissions needed to read a user's calendar?"
- "Summarize the MS guidance on Teams app manifest versions."

## Install

1. Download the plugin package (`.zip`) from this page.
2. Upload it via **Microsoft 365 admin center › Manage apps › Upload custom
   app**, or sideload it with the Microsoft 365 Agents Toolkit for testing.
3. In **Cowork › Sources & Skills › Plugins**, enable **My MS Learn Plugin**.
